# 方言优化与输入记忆：数据、排序与边界

Azki 有两个**可选**的本地能力：

1. **方言优化**：用户选择自己所在地区后，中文候选会获得该地区常用词、称谓、语气词和口头禅的排序加成，并补充地区表达；关闭后行为与旧版一致。
2. **输入记忆**：只记录用户实际采纳过的词、短语和组词，按输入频次、选择时的候选位置和近期采纳率调整排序。它不记录未提交草稿、光标上下文、剪贴板或文档内容。

两者都只在本机运行，不联网、不上传，也不会改变内置词库文件的字节。设置入口在主应用「输入」页的「方言优化」「输入记忆」卡片。

## 句尾习惯

词语和句尾语气词在同一份词库 `Sources/Core/Resources/dialects.json` 里，由 `scripts/build_dialects.py` 生成。其中调研来的语气词和程度词取自 `DataSources/dialect-sources.json`，每行都记录来源网址；原有的手写词条没有逐条来源。语气词的分级如下：

| 级别 | 含义 | 候选位置 |
| --- | --- | --- |
| 3 | 在该地区语料中实测，显著高于普通话 | 第二位 |
| 2、1 | 实测差异较小，或只有文献记载 | 第三位 |

- 只有输入的拼音确实以该语气词结尾、前面能解码成完整内容，且切分落在音节边界上时才生效，所以 `hua` 不会被拆开。
- 永远不占第一位，是否升到第一位由输入记忆决定。
- 以下内容不进入运行时数据：实测与普通话无差异的、普通话本身高频的（每百万 500 次以上）、来源无法复核的、许可不允许的、不适合默认推荐的、无法用拼音打出的。
- 语气词的疑问、祈使等用法不做判断：拼音里看不出语气，实测数据也几乎无法验证这一字段。
- 调研来的程度词按普通方言词条使用，尚未判断是否紧贴形容词；句式需要语法规则，尚未使用。

## 方言数据

运行时数据为 `Sources/Core/Resources/dialects.json`，由 `scripts/build_dialects.py` 生成。它由两部分组成：848 条手工整理的词条，没有逐条来源，准确性未逐条核实；以及调研得到的语气词和程度词，每条在 `DataSources/dialect-sources.json` 记录来源。这不是完整的方言词典。

### 覆盖范围

当前 33 个地区包、1050 条词条和 236 条句尾语气词，覆盖：

| 区域 | 地区包 |
| --- | --- |
| 官话 | 东北、北京、天津、河北、山东、河南、山西、内蒙古、陕西、甘肃·宁夏、青海、新疆 |
| 西南官话 | 四川·重庆、云南、贵州、湖北 |
| 湘语、赣语、江淮官话 | 湖南、江西、安徽、江苏 |
| 吴语 | 上海、浙江 |
| 闽语 | 福建·闽南、福建·福州、广东·潮汕（潮汕片）、海南 |
| 粤语 | 广东·粤语、香港、澳门、广西 |

同一地区包可以跨省使用；例如「东北」包含辽宁、吉林、黑龙江和内蒙古东部，「四川·重庆」覆盖川渝。用户选择的是地区包，而不是行政区 JSON。地区包的 provinces 只用于设置页说明。

### 词条结构

    {
      "id": "sichuan-chongqing",
      "name": "四川·重庆",
      "family": "西南官话",
      "provinces": ["四川", "重庆"],
      "summary": "……",
      "entries": [
        {
          "text": "巴适",
          "readings": ["bashi"],
          "boost": 5,
          "kind": "形容词",
          "note": "舒服、好"
        }
      ]
    }

- readings 只允许小写 ASCII 字母，直接复用普通拼音键盘；带声调、空格或数字的读音不会被加载。
- 一个词条可有多个读音，用于普通话拼音与常见本地罗马字近似，例如粤语「唔该」提供 wugai（普通话）和 mgoi（粤拼近似）。
- boost 为 1–5 的区域内部权重：5 是较有辨识度的地区标记，1 是轻量文化词。它不是词频，也不改变内置词库权重。
- kind 只用于说明分类；note 是给设置页和数据审查用的简短释义。
- 加载时会校验版本、地区标识、重复词条、文本长度、控制字符、读音字母和 boost 范围；任一条不合法就整体拒绝，不会带着坏数据进入键盘。

### 排序方式

方言优化只在**中文**键盘、且用户已选择地区时生效：

- 输入编码与某个地区读音完全一致时，该词条以「方言」来源加入候选，获得 4.0 + boost × 1.6 的排序分；最高优先级约 12 分。
- 输入是地区读音的前缀时，作为补全候选加入，分数为 1.0 + boost × 0.9。只有输入至少两个字母才会做补全，避免一键弹出大量方言词。
- 已有内置候选的文本如果也是该地区词条，会获得有界的 boost × 1.8（上限 9）排序加成，因此「巴适」这类原本词频很低、但属于地区高频说法的词可以上浮，而不会无条件压过所有常用词。
- 地区词条同时作为补充词进入中文整句解码，因此连续输入时也能参与组句；显式自定义词条和内置词条仍然优先。
- 方言候选只影响排序和补充，不改变用户实际输入的拼音；关闭方言优化后不再注入任何方言候选。

## 输入记忆

运行时文件为 App Group 目录下的 input-memory-v1.json（InputMemoryStore），与 profile-v1.json 分开。文件是原子写入，并有文件锁；App 与键盘扩展不能静默覆盖对方的数据。默认最多 3,000 条、2 MiB；超过上限按综合得分和最近使用时间淘汰。文件损坏时保留为 input-memory-damaged-*.json，随后以空记忆继续，避免一条坏 JSON 永久禁用学习。

### 记录什么

只有用户实际采纳（点选、空格/标点/换行提交）的内容才会创建新词条：

| 事件 | 触发 | 作用 |
| --- | --- | --- |
| exposure | 已学习词条在一次组字过程中出现在候选栏前 6 位 | 同一组字过程只记一次，用来计算近期采纳率 |
| selection | 用户点选候选 | 记录编码、文本、候选中位置、是否自创、来源 |
| composition | 用户在同一次组字中先点选部分候选，再完成剩下的输入 | 把多个被采纳的片段合成一个用户自创短语 |
| 提交 | 空格、标点或换行采用整段候选 | 记录整句/整词；若此前有点选片段，再合成一个完整短语 |

**不记录**：未提交的拼音、被取消的草稿、光标前后文本、宿主文档、剪贴板历史、按键序列或任何可以还原整段文档的上下文。学习关闭后，键盘既不读取也不写入记忆；已有记录保留到用户手动清除。

### 权重如何变化

每个词条保存 selections、exposures、近期指数滑动计数、promotion（0–30）、最近选择位置、创建/最近使用时间和是否自创。核心规则：

- **深处才找到**：点选位置越靠后，promotion 增量越大。第 5 位及以后额外加 5 分；第 8 位首次点选可达到约 19.8 分，而下一次输入同一编码时，promotion ≥ 9 且有近期采纳的词会直接占据第一行。
- **反复采纳**：每次采纳都会继续提高 promotion 和熟悉度，promotion 上限 30；因此常用词会稳定在前列。
- **采纳率下降则降权**：每次作为已学习候选出现但没有被采纳，会按 0.72 + 0.23 × 近期采纳率 衰减 promotion。如果长期只出现不被选，promotion 会跌破 9，失去第一行保留位；综合分还会乘上近期采纳率和时间衰减。
- **时间衰减**：排序分按最近使用时间指数衰减，约 45 天半衰期；超过 60 天未使用会逐渐失去整句解码补充权重；一年以上且只采纳过一两次的词条会被清理。
- **自创词**：来源为「拼接」「原文」「记忆」或由多个片段组合出的短语会标记为 userCreated，获得小幅额外基础分；它仍然必须通过实际采纳来增长，不会凭一次输入永久置顶。
- **第一行保留位**：只有编码完全一致、promotion ≥ 9、近期采纳率至少 0.2、最近使用未过久的词条才获得第一行优先（500 分）。前缀补全、低采纳率或久未使用的词条不会获得这个保留位。
- **显式内容优先**：快捷短语、用户导入的自定义词和内置词库仍是独立来源；学习只在既有排序之上加有界分，不会删除或改写它们。

## 隐私与系统边界

- 两组功能都只在本机执行；运行时代码没有网络请求、遥测或云端候选。
- 方言数据随包离线提供；输入记忆写入 App Group 共享目录。App Group 或完全访问不可用时，以系统实际权限和各进程本地存储为准，不能保证 App 与扩展自动合并。
- 清除记忆不会影响自定义词库、快捷短语、外观或内置词库。
- 关闭学习不等于删除；设置页提供单独的「清除本机输入记忆」并二次确认。
- 当前只在中文候选路径启用方言优化；英文补全和日文假名路径不注入方言词。输入记忆覆盖三种语言，但中文之外没有整句解码补充。

## 数据来源与维护

`dialects.json` 整体按 CC BY-SA 4.0 提供，与 MIT 代码分开；调研数据只保存字形、读音和证据等级，不含引文。

更新步骤：

    python3 scripts/build_dialects.py          # 重新生成 Sources/Core/Resources/dialects.json
    python3 scripts/build_dialects.py --check  # 验证生成文件与脚本一致

新增词条时优先使用常见、非辱骂性、可解释的日常表达；不要把网络梗当作唯一依据，也不要把某个地区的说法写成对所有使用者的刻板断言。地区包是可选辅助，不是语言身份判断。
