Project: https://www.edrdg.org/wiki/JMdict-EDICT_Dictionary_Project.html

Changes: select common-priority reading/spelling pairs; obey re_restr and

REGIONAL DIALECT CATALOGUE
Sources/Core/Resources/dialects.json combines an editorial compilation of regional words
with researched sentence endings and intensifiers. Researched rows carry forms, readings
and an evidence tier only, with no quoted text; each row's source is in
DataSources/dialect-sources.json. They come from Wiktionary (CC BY-SA 4.0), CC-Canto
(CC BY-SA 3.0), Wikipedia (CC BY-SA 4.0) and published dialect studies, with tiers from
rates measured in HKCanCor (CC BY 4.0), Tatoeba (CC BY 2.0 FR) and other public corpora,
of which only derived rates are used. The file is offered under CC BY-SA 4.0, separately
from the MIT code. It is used only when the user opts into dialect optimisation.

QUALITY AND WARRANTY
Dictionary ranking uses source priority hints, word frequencies and
transparent editorial preferences, not a bundled language model. The keyboard
also has an optional, local-only per-user candidate memory that learns from the
user's own adopted choices; it is not trained on document context and does not
change this dictionary. Entries may contain outdated, offensive or specialist
vocabulary. Data is provided without warranty; see the full licenses and EDRDG
statement included in this directory.

Emoji suggestions are derived from the Unicode CLDR 46.1.0 annotations (zh, en),
Copyright Unicode, Inc., via cldr-json. The license is included in Unicode-License.txt.
